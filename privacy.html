Who is responsible

Knut Wien, MultiPitch AS, Norway. Contact: knut@multipitch.no.

Whose data

The application is used only by Knut Wien, and only with Google accounts he owns. It processes no data about any other user of the application.

What data is accessed

With the account owner's consent, the application may access Gmail messages and settings, Google Calendar events, Google Drive files and Google Contacts in the owner's own accounts, as listed on Google's consent screen.

How the data is used

The data is used only to perform tasks the account owner asks for: finding receipts and documents, organising e-mail, managing calendar entries and working with files. It is processed on computers owned by Knut Wien.

Sharing, selling and advertising

Google user data is never sold, never used for advertising, and never shared with third parties, except where the account owner himself instructs that a specific message or file be sent, or where required by law.

Storage and security

Sign-in credentials are stored encrypted on the owner's computers and are never published. Data read from Google is kept only as long as the task needs it, unless the owner decides to file a copy in his own records.

Limited Use

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Withdrawing access

Access can be withdrawn at any time at myaccount.google.com/permissions. Stored sign-in credentials are then deleted from the owner's computers.
